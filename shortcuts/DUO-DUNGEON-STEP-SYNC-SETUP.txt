DUO DUNGEON — APPLE HEALTH STEP SYNC
=====================================

Shortcut name: Sync Duo Dungeon Steps

Create these actions in Apple Shortcuts, in this order:

1. FIND HEALTH SAMPLES
   - Health Type: Steps
   - Start Date: Today
   - (If available) Sort by Start Date, newest first
   - Do not add a limit.

2. CALCULATE STATISTICS
   - Operation: Sum
   - Input: Health Samples from action 1

3. FORMAT DATE
   - Date: Current Date
   - Format: Custom
   - Custom Format: yyyy-MM-dd

4. TEXT
   Enter this URL, replacing the bracketed placeholders with Shortcuts Magic Variables:
   https://duodungeon.com/?duoSteps=[SUM]&duoDate=[DATE]
   [SUM] = result from Calculate Statistics
   [DATE] = result from Format Date

5. OPEN URLS
   - Input: Text from action 4

6. RUN THE SHORTCUT
   - Allow access to Apple Health when prompted.
   - Confirm the correct Duo Dungeon account when the game asks.

IMPORTANT
- Duo Dungeon credits steps to the account currently signed in on the device.
- The game asks for confirmation and refuses Health sync while signed out or in guest mode.
- The Shortcut itself does not store account credentials or choose an account.
- On a shared device, sign out before handing the device to another player.
- This Shortcut sends today's total. Re-running it does not pay rewards twice; only the increase since the last successful sync is rewarded.

NOTE
Apple Shortcuts action labels can vary slightly by iOS version. This is an action-by-action setup guide, not an installable Apple-signed .shortcut package. An iCloud install link can be added after the Shortcut is created and shared from the Shortcuts app.
