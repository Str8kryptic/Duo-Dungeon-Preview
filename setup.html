QUICK SETUP · ABOUT 2 MINUTES

Build your step-sync Shortcut

1
Open Apple Shortcuts

Tap the button below, then choose New Shortcut and name it Sync Duo Dungeon Steps.

2
Find today's steps

Add Find Health Samples. Set Type to Steps and Start Date to Today. Sort newest first if the action asks.

3
Add Calculate Statistics

Choose Sum and use the Health Samples from the previous action as input. This gives the total steps recorded today.

4
Format today's date

Add Format Date. Use Current Date, Custom format yyyy-MM-dd.

Make sure it's going to the right crawler

Keep Duo Dungeon signed in to the account that should receive the steps. When the Shortcut opens the game, Duo Dungeon will show the signed-in email and ask you to confirm before rewards are applied.

If you're on a shared device, sign out before another player uses the game. The Shortcut never chooses an account; the active Duo Dungeon session does.
